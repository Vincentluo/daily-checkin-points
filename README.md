# 每日打卡 · 积分乐园（深圳小升初版）

一个**纯前端、单文件、可离线运行**的家庭习惯打卡 + 小升初衔接练习应用。
由原 workbuddy 版「每日打卡·积分乐园」重制升级而来：**保留角色 PIN 门禁与打卡/积分/商城结构，新增"每日一练"学科题库与家长后台**，内容对标深圳教材。

## 一、角色与默认密码

| 角色 | 默认 PIN | 说明 |
|---|---|---|
| 👨‍👩‍👧‍👦 家长 | `1111` | 后台：查看孩子打卡、兑换审核、发/扣积分、改密码、管理奖品 |

> 首次进入后请家长在「后台」里改掉默认密码。

## 二、深圳教材适配说明（题库来源）

| 学科 | 版本 | 内容范围 |
|---|---|---|
| 数学 | **北师大版**（深圳小学通用） | 哥哥：六下负数/比例/圆柱圆锥 + 七上衔接（有理数/整式/一元一次方程/思维题）34 题；弟弟：四年级大数/运算律/图形 20 题 |
| 英语 | **沪教牛津版**（深圳小学通用，含 2025 新版"深圳印象"单元） | 哥哥：小升初语法 + 深圳地标词汇题 21 题；弟弟：三/四年级基础 16 题 |
| 语文古诗 | **部编/统编**（全国统一） | 哥哥：小学必背 + 初一上《观沧海》《论语》等 12 题；弟弟：低段必背 10 题 |

合计 **113 题**，每题含选项、答案、解析与分值。

## 三、功能规则

- **打卡**：学习/运动/知识/古诗/英语 5 类，每项每日 1 次 +10 分；一日 5 项全勤额外 +20；连续打卡每满 7 天额外 +50。
- **每日一练**：哥哥每天数学 3 + 英语 2 + 古诗 1 共 6 题；弟弟数学 2 + 英语 1 + 古诗 1 共 4 题。答对按题给分，答错看解析，**每天一组，次日自动换题**（按日期轮换题库）。
- **积分商城**：孩子用积分申请兑换 → 家长在「兑换审核」通过或拒绝（拒绝自动退分）。
- **数据**：全部保存在**本机浏览器 localStorage**，可在家长后台导出/导入 JSON 备份。

## 四、本地预览

直接用浏览器（Chrome/Edge）双击打开 `index.html` 即可，无需安装任何东西。

## 五、部署到 GitHub Pages（免费，手机也能访问）

### 方式 A：GitHub 网页上传（最简单）
1. 登录 [github.com](https://github.com)，点右上角 **+ → New repository**，仓库名随意（如 `checkin-points`），选 **Public**，勾选 **Add a README file**（可选），创建；
2. 进入仓库 → 点 **Add file → Upload files**，把本文件夹里的 `index.html`（和可选 `README_部署与使用说明.md`）拖进去 → **Commit changes**；
3. 仓库 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 `main` + `/ (root)` → **Save**；
4. 等 1-2 分钟，访问 `https://你的用户名.github.io/checkin-points/` 即可（页面底部会显示该地址）。

### 方式 B：GitHub Desktop
下载 [GitHub Desktop](https://desktop.github.com/) → File → New repository（本地建库）→ 把两个文件放入仓库目录 → 点 **Publish repository** → 再按方式 A 第 3 步开启 Pages。

### 方式 C：命令行
```bash
git init
git add index.html
git commit -m "每日打卡积分乐园 深圳小升初版"
git branch -M main
git remote add origin https://github.com/你的用户名/checkin-points.git
git push -u origin main
```
然后在仓库 Settings → Pages 按方式 A 第 3 步开启。

> ⚠️ 注意：localStorage 数据存在**各自设备的浏览器**里，家人各自手机打开是各自独立数据（此版为无后端纯前端，无法跨设备同步）。如需全家共享进度，需后续接入后端（可再找我规划）。

## 六、扩展题库（自行加题）

用记事本打开 `index.html`，搜索 `const MATH6=` / `const ENG6=` / `const POEM6=` / `const MATH4=` / `const ENG4=` / `const POEM4=`，在数组末尾按此格式追加一行：

```js
{q:"题目文字",o:["选项A","选项B","选项C","选项D"],a:0,p:15,s:"学科 · 知识点标签",ex:"答案解析"},
```

- `a`：正确选项下标（0~3，从 A 开始数）
- `p`：答对得分（建议 10~25）
- 保存后在浏览器刷新即可生效。
